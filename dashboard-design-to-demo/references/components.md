# 素材与实现选择

按这张稿中实际出现的内容选择做法。用通用工具处理交互。涉及既有项目的组件、操作实现或视觉资产时，普通项目先列明来源并取得同意，从零测试只使用当次输入。

| 图里出现的内容 | 实现依据 | 做到什么程度 |
|---|---|---|
| 排版、控件、列表、图表 | 原尺寸图、可读字段和状态；有分层稿时使用对应图层 | 布局和文字可编辑。选中、筛选和详情由同一个对象或数据记录驱动。 |
| 照片、纹理、装饰、固定角度插画 | 原图中清晰可见的区域，或用户提供的独立素材 | 保持默认构图；分离前景对象、界面与背景，局部放大时检查切图边缘和遮挡区域。 |
| 可绕看的物体、表面或空间场景 | 优先使用用户原模型、多视图、地图或测量数据。可从同类结构或照稿建模起步，按原图修改可见轮廓、部件、材质与照明 | 将透视机位对回原稿，轮流用单色和完整材质检查造型与受光。整景和局部的查看范围依据用户意图。预览说明应指出推定部位及其依据。 |
| 区域变色或更换表面材质 | 项目部件分区、材质槽或精细遮罩 | 将基色、纹理和受光分别处理。基础色变化覆盖同一部件的所有视角，玻璃、文字、开口、配件和背景按其真实归属处理。 |
| 动效、轨迹和粒子 | 优先依动画参考的帧序、位置、速度、密度、淡入淡出和循环；单图只能给出某一时刻 | 提供可复现的对照时刻。需要改变视角时，运动元素锚定在对应物体或场景坐标；播放、拖动与复位的行为明确。 |

## 多视角的细节

- 将角度、缩放和选中对象视为同一组查看状态。旋转过程中保持比例、部件位置和材质连贯。对平面地图、文字面板只提供与内容相符的查看方式。
- 为镜头选择围绕主体的旋转中心。缩放至近景时避免截去待检查部位；复位恢复原始视角与主体占比。桌面支持鼠标，目标设备包含触屏时提供对应的拖动和双指缩放。
- 默认角度和新增角度都用同一可操作主体呈现。多面材质可以各有差异，例如正面的玻璃与背面的金属；这些差异需符合物体结构，并在同一套光照下表现合理。
- 高程、结构尺寸、品牌专属细节或色样需要精确时，在对稿说明中标明可核对的来源。只有一张图时，核心结构按同类常见做法补全，在交接中注明推定部位。三维材质按[三维结构与材质细则](spatial-materials.md)处理。

## 随包资源

随包提供定位光圈与告警样式。具体设备的形体、连接关系、材质和标记依本稿构建。

定位点可使用 `assets/alarm-pulse.css` 中的 `.location-halo`。只把这个类加到独立外晕层，父组负责定位，中心亮点和文字放在同级。原始大小、色相、软边与静态透明度由本稿的样式确定；若采用呼吸效果，给该层加 `data-breathe="true"`。元素基准尺寸对应原稿。静态稿里，定位图标或亮点下方有宽而柔的半透明光圈时，可选 `data-breathe="inward"` 让收缩更容易看清。用户要求呼吸稍快、收得更小时也用此预设。该预设每轮 2.15 秒，直径从基准的 86% 变化到 108%。可单独调整外晕上的 `--halo-period` 和 `--halo-min-scale`。减少动态效果时自动恢复静态外晕。

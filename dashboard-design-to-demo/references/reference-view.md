# 从原稿机位反修三维场景

把参考图当作要用相机重新拍出来的一张画面。输出包括可复位的原稿机位，以及从这个机位可以连续绕看的同一个场景。默认机位的可见内容按原图验收；遮挡处与背面只对有依据的部分作精确声明。

## 选参照，校准相机

1. 在原尺寸上圈出主视觉与被界面遮挡的范围，记录哪些线条决定物体身份。对单件产品选外轮廓、部件接点、开口、接地处；对场景从前、中、远景选分布在不同深度的物体，标出数量、占地、空隙与相互遮挡。辨认不清的部分单列。多张独立图各自选点。
2. 先定可见的比例和结构关系，用分布在全画面、不同深度的点联合估计透视相机的朝向、俯仰、视场角、距离、目标点和取景范围。近似侧视或长焦的原稿可用较远机位和较窄视场对图。单图通常有多组可能解，以符合常见物体比例、换角度仍自然的一组为起点。
3. 保存相机与复位参数。后续对比固定视口、设备像素比、镜头、曝光、动画时刻与数据。将原始图和浏览器真实渲染按相同坐标叠加；比主视觉时按同一框裁两图。独立拉伸、移动主体或事后变形截图会破坏对照依据。若多个深度的参照一起错位，回到镜头校准；单个部件错位时先改该部件。

## 从差异决定改哪一层

| 同机位可见的差异 | 回到场景中怎样改 | 下一次渲染核对什么 |
|---|---|---|
| 外缘、开口或物体身份有偏差 | 用单色模型叠轮廓。改变截面、曲率、厚度、轮拱或屋顶形体，必要时重建局部；把窗、灯、洞口等分成独立部件。通用模型可作为起点，也可依原图轮廓直接搭建。 | 在自然尺寸下核对关键轮廓与识别部件，在斜侧看厚度、开口、远侧遮挡。 |
| 场景显空、建筑重复或数量有差 | 按区域核对可见物件、相邻关系和尺度。先补影响构图的楼体、道路、前景遮挡或远景轮廓，再补次要细节。重复物件可共享几何与材质。 | 按原图逐区勾对物件和空隙，检查入口对着哪条路、哪栋楼挡住后一栋、背景占了多少画面。 |
| 颜色接近，表面仍像塑料、平纸或黑片 | 在同一物体分别取亮面、中间调、暗面与反光边。拆分固有色、纹理尺度、细微凹凸、粗糙度、透光与反射；从原图提取的局部细节先校正透视和原有光影，再写回对应表面。 | 对比漆面亮带的形状和宽度、玻璃可见内部的程度、粗糙面的颗粒尺度。转过原机位，确认纹理固定、反光自然移动。 |
| 明暗和前后层次失真 | 从投影方向、高光形状与边缘软硬估计主光方位、光源面积和环境反射。先校准大明暗与接触阴影，再匹配小高光、发光衰减、雾或景深。只采用原稿中有依据的效果。 | 比较前中远景的明暗顺序、阴影落点、最亮区域的位置和面积。临时关闭发光或景深，看底层形体是否成立。 |
| 热度或科技效果像均匀画线 | 先校准实际峰谷、色层或发光结构的位置，再从原稿提取渐变宽度、主次轮廓线、局部峰光、粒子疏密与暗部。按对象空间、高度或数据绑定对应效果。 | 同时比较一个亮区和一个暗区；从低侧或背侧追踪同一条线、同一层或同一圈光带。 |

每轮挑出最妨碍辨认主体的偏差，记下原图位置、可见现象、拟改的对象或光源。改完在同一机位重拍，保存改前、改后与原图的同一区域。若形体已经偏离，调色不会让外轮廓对齐。若多个彼此独立的材质一起过亮，先检查光照、曝光或色彩转换。优先采用成本更小且能解释可见差异的修改。

## 透视绕看与隐藏面

- 互动镜头采用透视投影，围绕稳定的主体中心或用户选中的场景焦点运动。通过正常观察距离、视场角和俯仰建立近大远小与前后视差。滚轮沿观察方向靠近或远离。限制最近距离，避免穿进表面；缩放与聚焦后仍能复位。启动拖动、经过原机位与松手时连续呈现同一模型、材质与灯光。
- 从首页小幅拖动，观察一个近部件与一个远部件的相对位移，再连续走过侧面、背面、正面、整圈回到起点。核对遮挡、玻璃反射、标记与接地关系，排除等轴展示、过强广角、镜头跳变、屏幕固定的高光、双重轮廓与截面露洞。若原稿本身是工程正投影，且项目同时要求严格复刻这种投影，应与用户明确对稿视图的用途；自由绕看始终采用透视镜头。
- 只有一张图时，图外的面依据可见轮廓的延续、同类结构、同一材料和光照补全。区分可推定的对称结构与带方向的文字、格栅、灯型和装饰。具体型号的不可见结构需要车型资料、多视图或原模型才有事实依据。

## 交付判定

默认机位和绕看分别给出结论。原尺寸并排时仍能指出“像另一辆车”、建筑缺失、光层或材质显著不同，记作“原机位待修”，回到对应步骤；绕看中出现破面、假视差、贴图突变，记作“绕看待修”。两项分别附原图与实拍证据。只有技术操作通过或整页像素差很小，仍不足以作出视觉通过的判断。

原机位目标是设计者在原尺寸与关键局部都能认作同一对象、同一画面。按素材可辨认精度及项目已约定的容差复核。遇到按现有资料无法消除的明显差异，指明部位、依据和最少需要补充的资料，保留待确认状态。用户保留最终视觉验收权。

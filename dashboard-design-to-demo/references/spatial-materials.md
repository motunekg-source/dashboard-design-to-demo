# 三维结构与材质细则

先找出图中最能决定空间解释的线索，例如围绕塔口的椭圆线、闭合等高线、穿过玻璃能看见的框架、前后轮的轴线。有明确图例、数据、原模型或用户说明时优先采用。下列做法按主体特征选用。

## 连续曲面与多来源纹理

- **球体或其他连续表面。** 先制作覆盖整个表面的统一底色与起伏。地球用同一套经纬坐标对齐海岸线、地形和点位。需要补原图特有的山脉细节时，将校正后的局部细节写回对应地理位置，所有角度采用同一套材质和灯光。
- 两份素材先对齐结构，再匹配同类区域的底色、明暗范围、细节尺度与清晰度。分别检查海洋与陆地，处理原图已有的投影和高光。过渡应跨过拼接带平滑变化，经度首尾也须相接。若仍看得出一块原图边缘，改用统一底图重建这段细节。扩大模糊范围会同时抹掉海岸与纹理。
- 检查时固定灯光，慢慢转过旧素材边界，在边界两侧和中间停下，放大同一片海面与海岸。正常的曲面明暗渐变应连续，岸线跨过接缝时位置与细节应接得上。

## 空间分层与环形结构

- **高度或数据决定颜色。** 先定义变量与颜色的对应关系，所有视角共用。以分层热力山体为例，先建连续的山体与峰谷，再用同一组高度阈值生成位于不同高度的层面、露出的侧缘或闭合等高线。低层取原稿的蓝青色，向高处过渡到红橙，峰顶保留原图中的亮色。前坡、后坡和侧面在同一高度使用同一基础色。若原稿表现为有厚度的叠层，应做出可从侧面读出的层厚；连续坡面则让等高线沿实际山坡闭合。图例若表达温度、密度等独立数据，按对应数据分层，避免把所有热图都解释为高度。
- **绕轴重复的图案。** 以冷却塔、储罐等为例，先按高度画出半径变化的轮廓并绕轴成形，分别处理外壁、内壁、开口与塔沿。用“绕塔一圈的位置”和“从底到顶的高度”定位纹理。相同高度的环带闭合，规则点阵在首尾对齐，材料的间距与粗细按原稿校准。局部阀门、门洞、编号等独立细节只出现在所属位置。光照可让一侧更暗，环带不会因此倾斜或断开。
- **清晰度。** 细光圈、点阵和扫描带优先用可重复的小纹理、线条或程序绘制，缩小时做抗锯齿，放大后仍能分辨层次。厂房屋顶和墙面各用对应表面纹理，排除原图里遮在前面的塔、文字和告警图标。

## 产品、玻璃与换色

- 用户本次提供的基模可改形。原稿中的特征难以由基模得到时，按外轮廓与特征线重建相关曲面或部件。用原稿机位验证身份特征，并在其他方向检查长、宽、高与承重部件位置。车辆按具体车身类别核对轴距、轮距、前后悬、轮拱、驾驶舱体积和四轮接地。确认正看有车宽，侧看有车长，斜看时远侧车轮被车身自然遮挡。
- 将车漆、结构柱、车窗及天窗玻璃、灯具、橡胶胎、轮毂和车牌分配到清楚的表面或部件。玻璃表现应符合稿中的透光或染色程度。可用轻量环境反射、密封边和必要的舱内轮廓，让侧看和俯视都能读出玻璃的曲面与边界。玻璃高光随视角移动。深色玻璃也应保留玻璃特征。
- 换色只改车漆材质。轮胎和轮毂已有实体时，先去掉车身纹理里对应的轮影。标记、车牌及格栅按设计位置出现一次。对称几何可以复用，贴有文字、车牌或斜视透视的原图区域须分别处理。检查模型关闭纹理后的轮廓，再分别打开车漆与玻璃，定位重复轮廓、透明排序或共面表面造成的重影。
- 同样的方法适用于其他产品。例如带观察窗的设备，机壳、透明窗、密封边和内部零件各自有厚度与遮挡关系。换机壳颜色后，窗内设备仍从原位置可见。

## 资源与使用选择

默认用本次提供的素材或在本地新建轻量结构，按当次原稿调整。使用任何已有项目的资产，普通项目先逐项取得同意。从零测试排除这类输入。缺少专有车型、设备或建筑的背面时，将该处标为行业通用推定。用户提供专用模型、多面图或明确要求特殊造型时，优先匹配该对象。若指定结构仍无法确认，提出能解决该处的最少补充素材。

用户希望更精确时，可依据同类多视图建模，或选可修改、可随包交接的现成模型。采用外部素材时核对比例、部件划分、来源及使用条件，并在交接中注明。除历史复用需经同意外，路线新增了必需的外部资源下载、第三方联网重建或明显额外的 API 用量、费用时，才在开始该步骤前让用户选择。说明该资源具体改善哪处、依赖什么、预计代价和可用的轻量做法。用量未知时写明未知。用户选择轻量方式时，核心结构、材料归属和旋转质量仍按相同标准验收。日常 Skill 联网无须额外提醒。

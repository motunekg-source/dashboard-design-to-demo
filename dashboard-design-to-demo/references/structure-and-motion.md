# 结构、配置与动效实查
先列出主体、附属件、承重或安装关系、可切换配置和静置时应运动的物件。
* 浮雕类表面用同一空间材质覆盖整件。地球取前后两片山地，在同一灯光条件和近似尺度下检查细脊、坡面明暗和纹理密度。保留天然平滑的海洋。转过地理接缝再返回。
* 车辆等刚体按轴距、轮距、宽度和安装点建模。优先调相机与空间截面，禁止按单张截图分块拉伸刚体。去掉材质，从正、侧、后、斜前与斜后看白模，验车灯、格栅、轮拱、尾翼端板与支架的轮廓和连接，再恢复材质。全件查看时以完整边界适配视口。
* 对工装、桥架、管道等逐件说明它接在哪里。切到低侧机位，隐藏标记，核查实体支撑、接触或吊装。人工悬浮标记要随所属部件移动。
* 通过缩略图识别配置语义。款式变化落实到实际部件；同一机位与曝光截取每个选项的部件近景，检查可见差异、非目标部件及复位。选中边框或状态值不能单独作为通过证据。
* 地球展示默认慢转，交互时暂停，提供准确复位。流线依语义显示行进脉冲，无方向依据时用往返光点。定位外晕轻微呼吸，告警局部脉动，保持读数稳定。对二维和三维都先做静置检查，录取启始、中间、末段的真实画面；同时验证暂停或减少动态效果。地理标签和告警随空间物件，固定 HUD 读数留在屏幕上。
* 记录每项的原稿、实际机位、目标细节、结论和证据。浏览器实拍和人工对稿都通过才签为正式成品。阶段预览可提前给出，各项按实际状态注明。任何角度下形变、断件、悬空、材质掉档、配置无法辨认，或缺少必要动效及证据，均计待修。正式包运行既有同包验收，再核对批次原稿总数与独立待修清单。

## 定位失效发生在哪一步

* 正面有山脊、转过半圈只剩洲界时，把球体转到两个有山地的地点，各取相近大小的山地。分别只开基础色、凹凸和侧向光。如果去掉基础色后细节消失，补全球的高度或法线细节，再用原稿校准可见陆地。记录新增山形的依据，地形推定不能当作实测高程。
* 产品转后变形时，先关闭照片与反射，在透视视角检查刚体截面、轴距、前后宽度和附件连接。转动只更新相机或物体的刚性变换。校验完整模型含尾翼的边界、裁剪面和界面遮挡，在全件模式保留附件。修好形体再把灯、开口、轮圈和漆面逐件对回原图。
* 出现悬空时依次看无材质侧影、装配树与世界坐标。稿件读错了安装关系就重画结构图。已有安装点却悬空就修正单位、局部原点、父子变换或着地点。低侧实拍中追踪“底座—立柱—横梁—设备”；标注与报警图标允许悬浮，须能追溯所属设备。
* 配置先记录「选哪个选项 → 应出现什么肉眼可见的部件变化 → 哪些部件保持原样」。固定相机、灯光和动画时刻，裁掉选项卡片，先单看两张主体局部能否辨认款式。截图里如果只有边框改变，回到模型的对应节点或材质槽。
* 同机位落差大时，在原图上量主要轮廓的像素位置并读取亮面、中间调、暗面的小片颜色范围。轮廓差先改截面和镜头。灯光差再查方向、色彩空间、环境光、发光和雾衰减；界面与主体分开校正曝光。保留一张返修后的同机位实拍验证差异有没有收敛。
* 集成后再次验证首次打开、鼠标操作、空闲循环和减少动效设置。分别截相隔约四分之一周期的状态，明确变化发生在哪个对象，读数与样式是否稳定。使用完整周期取证时同时保存实际周期及帧序。

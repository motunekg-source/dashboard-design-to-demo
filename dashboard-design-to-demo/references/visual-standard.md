# 逐项视觉验收标准

公开版的首次成品以原尺寸、同机位看起来基本一致为准，逐张检查两三处能辨认设计身份的局部和各可见面板。适用三维的还须实际绕看、缩放和复位。采用随包工具给正式构建做量化签核时，再使用下面的五维量表。

## 哪些地方允许有细微差异

| 对象 | 依据与操作 | 放行条件 |
|---|---|---|
| 原图可见的二维界面、图表与数据标记 | 固定原尺寸、数据、字体加载状态和动画时刻。逐个面板与图表同坐标裁切，先按 1:1 看，再叠图定位。 | 可辨认的文字、数字、层级、间距、几何、颜色和图例对应关系逐项吻合。整体相似度不能抵消一个画错的图表。系统抗锯齿、原图压缩造成的单像素波动可记录；原稿不可辨认的字段须标示推定，影响读数或图义时补依据。 |
| 在原图中可见、需要延展的主视觉 | 先争取完全还原。将主体、遮挡和能辨认身份或主效果的局部提前圈出，在相同机位比较。多主体、多张有效参考视角各自评。 | 每个主体、每个有据视角的身份特征和主要效果吻合，硬性检查通过。使用正式量表时逐主体、逐有据视角评定。 |
| 图外、被挡住的区域及自由视角 | 采用可见结构的延续、同类物体构造、统一材质与灯光；收到其他角度或原模型后优先用作依据。 | 用连续操作验收结构、遮挡、表面密度、接缝与场景延展。在交付说明中点出主要推定部位。单图没有提供的角度不报还原百分比。 |

## 正式构建可选的 95 分人工量表

这是对设计特征的人工复核量表，由执行者看过实拍再填写。整页像素相似度、公共背景面积、DOM 项数均不计分。

| 维度 | 权重 | 参照实例 |
|---|---:|---|
| 轮廓与比例 | 25 | 山脊走势、塔身收腰、车顶弧度和轴距。 |
| 部件与空间关系 | 25 | 峰谷位置、门窗和轮圈结构、道路连通、前后遮挡。 |
| 材质与纹理 | 20 | 浮雕起伏、漆面与玻璃、点阵密度、热力色带。 |
| 光影与渐变 | 20 | 大面明暗、反光软硬、投影落点、亮带渐变范围。 |
| 构图与视觉效果 | 10 | 主体占比、镜头高度、粒子疏密、光晕范围。 |

每一维记录具体参照部位和实拍观察。“吻合”得该项满分。“细微”得该项权重的九成，只适用于身份和主要视觉特征都对上、需近看才能辨认的残差。“待修”或“依据不足”均须继续处理。各维得分相加，每个主体和视角独立达到 95 分，不四舍五入、不跨对象平均。留存原图与运行画面的同坐标局部，整齐的面板或大面积空背景不能替主视觉得分。举例：轮圈细部与漆面高光各有轻差，扣 2.5 与 2 分，合计 95.5；轮圈款式使整车一眼看成另一个车型，则直接返修。此例仅说明计分方法。

可辨认的二维元素缺失或错排、主物件形状或材质一眼不符、明显拉伸或接缝、结构缺件、套壳或串色、图框露边、道路或轨迹截断、缩放时前后景分家、绕看时切回照片等，均直接返修。单看默认画面得到的分数不能覆盖这些缺陷。

## 怎样从参考图重建容易出错的部分

| 原图中的特征 | 实现与实拍核对 |
|---|---|
| 浅色浮雕或低对比曲面 | 先还原亮部、中间调、背光面的大范围渐变，再调局部凹凸、受光方向和边缘软度。对比原图的亮面、山脊投影、球体下缘三处，再转到相反方向观察细节尺度与明暗是否连续。不要靠锐化轮廓制造浮雕感。 |
| 定位或状态标记的光晕 | 分开图标、中心亮点和半透明外晕。先对稿外晕的直径、色相、边缘软度和落点；外晕可轻微呼吸，中心与读数稳定。静态稿可用约 2.4 秒一轮、直径变化约 8% 作调试起点。用户希望节奏稍快、收缩更明显时，使用[素材与实现选择](components.md)中的收缩预设。按一整轮核对最小和最大直径，并确认点位中心稳定。原动图时序和用户明确的静态要求优先。减少动态效果设置下显示原稿的静态光晕。统计环、进度弧等编码数据的图形依其原意呈现。对比基准帧、最淡帧和最亮帧，转动后仍锚在对应点位。 |
| 紧凑的信息面板与组合图表 | 同框裁出标题、图形、图例和全部读数。逐行对位置、列宽、分隔线、字重、字号及单位。对环图比内外径、线宽、起点方向、分段与空隙、中心文字、图例和数值的列关系；其他图表对应核对刻度、编码与标记。按数据驱动绘制，实际改一项数据确认关联项同步。 |
| 山体、有陡坡的热图或有厚度的数据层 | 先用连续三维地形和数据场建峰谷、正反坡，再由高度或真实数据生成各面的渐变和等值线。粒子按表面面积布点，陡坡用表面坐标或按法线融合的多向纹理维持密度。原图投影只用在可见且像素足够的局部；背坡和掠射角低采样区从同一数据及材质重新生成。用漫射光临时关掉辉光，追踪同一条线过山脊到背坡，再恢复正式效果低角度近看，检查条纹拉长、拖影和侧壁断层。 |
| 柱体、塔罐、绕轴结构 | 按实际高度和周向位置生成可平铺材质。校准同一高度下点距、带宽和环带节奏，保证底色、凹凸与发光层在周向首尾同步。编号、开孔等局部特征保持真实位置。反射和方向光可随角度变化。临时关闭方向高光，在上、中、下各追一圈细节，检查背侧与接缝前后，再恢复光照复查。禁止将正面照片重复折返包一圈。 |
| 缩放能看见图框外的区域 | 开始建模时先从最近到最远机位估算可见范围。将固定面板、空间主体、周围环境分层，统一需要联动的空间坐标。球体与标记分离出透明轮廓，星点或底纹独立铺满可见背景。地形逐步延伸到自然边界；跨出原框的道路接到路口，跑道补完整圈，近地与远地统一比例、颜色及纹理密度。有依据的沙盘底座可保留其真实边缘。独立背景、远景低模或可平铺材质有助于兼顾体积和速度。 |

若输入是 GIF，回放中的主体随缩放时也要从每一帧分离背景，或在同一个空间场景中重演关键帧。直接缩放含底纹的矩形帧会在视口中露出图片边界。对带地面的场景，可临时关掉中心的参考纹理，检查道路、地形和建筑是否仍在同一坐标下完整相连，再打开纹理校准原机位。

球面等周期材质还要在实际缩放下跨越纹理首尾，检查细斜线是否只在远处或掠射角出现。发现问题时分开测试底色、凹凸、光照和纹理过滤，确保纹理的两端和缩小时使用的采样尺度都连续。

需要从原稿采样可见面的场景，逐层检查同一部位的基础色、原图采样范围、细线及辉光。遮挡边缘的采样权重沿模型表面平滑过渡；在目标大屏尺寸从侧后方核查暗斑、像素台阶与反复印出的原图轮廓。保留前景细线及原稿对远景的柔化，并复看较暗区域的颗粒密度。

## 怎样证明旋转和缩放都成立

1. 以自然透视从原机位连续转一整圈，经过侧面、背面与斜上方，停在最容易暴露纹理问题的角度。存在周期纹理时跨过接缝前、接缝处和接缝后三点；山地增加低侧或背坡近景。检查时把真实透视缩短与纹理自身拉伸分开，必要时临时用等距检查格看模型表面，再用正式材质复拍。
2. 在默认、斜侧和背向视角分别拉近、退到允许的最远处，再复位。纯二维缩放场景按支持的平移与缩放范围检查。巡视画面四边、四角、主体与背景交界；有回放与自由操作两种模式，两种都走。连续往返能发现单帧看不出的跳变。禁止以收窄原定缩放范围、裁掉边角或遮盖破口作为修复。
3. 留下实拍并排原图、关键局部、背侧近景、最远景和一段连续转动／缩放的视频或连续帧。各记录应指向能看清该问题的具体证据。发现可见差异先修复并重拍；任何已知问题角度都要按原路径复测。

## 单图补全的材质与大屏细节

- 在原图上区分物体本身的起伏、颜色与拍摄时的光照、大范围反射。连续曲面上的同一种材料共用底色、粗糙度、光照和细节尺度。用原图校准可见部位的形态和局部特征；把同一区域带光影的照片混入底材前，先分离大范围明暗。海面、玻璃等平滑区域保留真实的平滑度。
- 给每处已报告的交界保存可复现的相机方向、俯仰和缩放。沿该路径往返，分别在交界前、中、后取帧，并对比同种材料两边的亮度、色相、细节密度和反光过渡。重点看边界横穿同种表面的地方；地理海岸、物理拼缝等真实结构按原稿保留。视角无据的区域按同一物体的规则延展。如果转动时能看出补图的分界，继续返修。
- 带等值线、微粒或辉光的三维表面，先按表面或数据场生成连续的颜色、线芯和颗粒，再叠加独立的柔光。追踪同一特征经过原机位、侧面和背坡，区分透视缩短与材料变化。可读线条被泛光吞掉、峰顶两侧出现两种描线风格，均需返修。
- 在设计原尺寸和实际最大目标展示尺寸各拍一帧。记录 CSS 可见区域、设备像素比、实际绘图缓冲区像素和该尺寸的转动耗时。先确保前景线芯与相邻色层可分，再看辉光和远景景深。尺寸变化后重新分配绘图缓冲，允许按设备性能限制像素预算；限制生效后重新目视验证。将同尺寸、同位置的局部直接裁出，避免截图二次缩放制造清晰度。客观数字用于定位原因，不能替代目视。

## 怎样向用户交代细微差异

达标且有残差时，随成品简写“部位和差异 → 在哪个视角可看到 → 可怎样进一步校准”。例如“斜前方的轮辐边缘比原图略厚。若需精调，可在当前 AI 对话中附轮毂近照，并要求只调整轮辐截面，保持轮径和车漆。”未知背面另写推定依据。优先给本地可行的下一步；只有用户想进一步使用额外下载、需登录的资源或额外付费重建时，才说明具体条件和代价并让用户选择。有硬性缺陷或未过所用量表时，在记录中写明对应部位和待修原因。进入耗时精调前先给当前最佳阶段预览。同一处两轮均无可见改善时停在当前稿，等待用户选择后续。有实质依赖时说明最少需补的资料。
